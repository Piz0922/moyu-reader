# 摸鱼阅读器设计访谈

状态：各项需求已确认，用户已明确“开始制作”，第一版已实现。最后更新：2026-10-30。最终规格见 [spec.md](spec.md)，验证范围见 [validation.md](validation.md)。

## 用户已明确的方向

- 自己制作阅读器；试用 FloatingNovelReader 后，最不满意的是鼠标移入窗口时出现黑色背景的文本信息。尚未核实该信息在原软件中的具体类型。
- 阅读区域呈现为类似贴图的一块正文，可放置在网页上方。
- 正文不提供文字选择，按住正文可拖动整个阅读区域。
- 普通滚轮滚动正文；Ctrl＋滚轮调整字号。
- 拖四边中点调整宽度或高度。
- 拖四角等比缩放阅读区域和字号；拖四边只改变区域宽度或高度，字号不变、正文重新换行。
- 双击阅读区域隐藏。
- Windows 桌面悬浮窗，跨应用置顶。
- 第一版支持 TXT 和 EPUB 电子书。未将粘贴文本列为已确认需求。
- 默认白底深灰字，无标题栏、可见边框、阴影或常驻按钮；背景颜色与透明度可调。
- 鼠标移入正文不出现说明文字、黑底信息条或自动工具栏；边缘只通过指针形状提示缩放。正文右键主动呼出操作菜单。
- 双击完全隐藏，以可自定义的全局快捷键切换隐藏／显示，托盘提供恢复入口，屏幕不留小标记。
- 制作书架。单击右下角托盘图标恢复隐藏前的页面；托盘右键显示菜单，包含“书架、设置、退出”，不是直接打开书架。正文右键菜单保留书架入口。
- 一次只显示书架或阅读页中的一个；打开书架先隐藏正文，选书后回到原悬浮位置阅读。书架使用独立的正常尺寸，不覆盖阅读区域尺寸。
- 关闭页面或双击正文均不结束进程；只有托盘右键菜单中的“退出”才结束程序。页面恢复以隐藏前页面为准；启动时恢复上次页面，首次启动显示书架。
- 书架采用紧凑列表，显示书名、格式、进度，按最近阅读排序；支持搜索、文件拖入、按钮导入和移除书籍，首版不做封面墙。
- 导入时将电子书复制到程序目录下单独的资源目录；从书架删除只清理程序管理的副本及记录，绝不删除原文件。
- 书籍、配置、书架记录和阅读进度全部保存在程序旁的资源目录，分类组织；移动整个程序文件夹可带走全部数据。资源目录不可写时明确提示，不静默改用其他路径。
- 交付 Windows 便携版程序文件夹和完整源码；解压后双击 EXE 运行，运行依赖尽量随包提供，不要求安装开发环境。
- 连续滚动、跨章衔接，无常驻滚动条；缩放或重新换行时，以视口顶部附近的正文为锚点尽量保持位置。
- 默认隐藏／显示快捷键为 Ctrl＋Alt＋空格，可修改，占用冲突在设置中提示；恢复原位置和进度，不主动抢走其他软件键盘焦点。
- 初始字号范围 8～72，阅读区域最小约 160×100；等比缩放遇到限制整体停止，保持比例；托盘提供“找回窗口”。
- 每本书独立保存阅读进度；全局保存一套窗口位置、大小、字号与外观偏好，切换书籍不改变窗口尺寸。数据本地保存。
- 普通可重排 EPUB 使用统一字体与配色，保留章节和插图，插图适应区域宽度。首版不支持漫画、固定版式和 DRM 电子书。

## 当前决策树

- 使用目标
  - 已确认痛点：鼠标移入窗口时出现黑底文本信息。
  - 已确认：只用光标形状提示边缘操作，正文右键才显示菜单。
- 悬浮范围
  - 已确认：Windows 桌面置顶，跨应用使用。
  - 已确认：恢复阅读区域时不主动抢走其他应用键盘焦点。
- 缩放语义
  - 已确认：四角等比缩放区域与字号；四边只改变区域；Ctrl＋滚轮只改变字号。
  - 已确认：字号 8～72、区域最小约 160×100，等比缩放整体限位；以正文锚点保持阅读位置。
- 阅读内容入口
  - 已确认：TXT 和 EPUB。
  - 已确认：需要书架；EPUB 支持普通可重排文字书、章节与适宽插图。
  - 已确认：书架与正文互斥显示、各自保存尺寸；列表书架，支持搜索、导入、移除。
  - 已确认：程序目录下独立资源目录保存导入副本，移除不删除原文件。
- 外观
  - 已确认：白底深灰字，无标题栏、可见边框、阴影或常驻按钮；背景颜色与透明度可调。
  - 已确认：正文右键菜单进入设置；无悬停说明、无常驻滚动条。
- 隐藏与恢复
  - 已确认：双击隐藏；全局快捷键切换；托盘恢复；无屏幕残留标记。
  - 已确认：Ctrl＋Alt＋空格切换，可修改；原位置与进度恢复，阅读区不抢焦点。
  - 已确认：托盘单击恢复原页面，右键菜单含书架／设置／退出；只有托盘菜单退出才结束程序。
- 数据记忆
  - 已确认：每书进度独立、窗口和外观全局保存。
  - 已确认：恢复上次页面，首次使用显示书架。
  - 已确认：设置、进度、书架记录统一放在资源目录，随整个程序文件夹移动；不可写时明确提示。
- 交付形态
  - 已确认：解压后双击运行的 Windows 便携版，附完整源码；依赖尽量随包提供。

当前没有待选择的产品分支。用户已完成整体确认，不再将常规实现细节扩展为新的需求访谈。
