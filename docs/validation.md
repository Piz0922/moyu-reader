# 第一版验证记录

日期：2026-10-30。环境：本机 Windows 10 x64，.NET SDK 10.0.400。

## 已完成

- Release / win-x64 自包含发布成功，零编译错误和警告。发布目录包含运行时，运行无需开发环境。
- 12 项核心集成检查通过：TXT 多种编码、空书拒绝、长段 Unicode、EPUB spine 顺序与实体、图片、固定版式与 DRM 拒绝、路径边界、导入去重与副本独立、移除不影响原文件、移动程序目录、损坏配置恢复、不可写目录提示、四角与四边缩放约束。
- 17 项实际 WPF 窗口检查通过：页面互斥、正文菜单、路由滚轮事件、章节目录、长正文定位、字号和宽度变化的锚点保持、隐藏与恢复、保存重读、非法快捷键拒绝、EPUB 图片渲染、移除副本与防止旧进度回写、长书中段排版。
- 约 1.6 MB 合成小说共 6000 段，打开并定位到中段约 7.3 秒（包含测试等待），不是性能承诺。
- 人工查看程序内渲染输出：书架、正文、设置、EPUB 插图。文字和按钮未见溢出，正文无标题栏、工具栏或提示层。

## 验证边界

computer-use 的 Windows 原生通信管道不可用，首次连接、重试及重置会话后均失败。因此未通过桌面自动化执行真实鼠标拖角、双击、托盘点击或跨显示器操作；程序内窗口测试与几何测试不能替代这些设备操作的实机验收。

已覆盖 API 级窗口显示逻辑与数据保护。多显示器不同 DPI、极长小说性能以及用户自己的 EPUB 排版仍需试用反馈。

## 复现

运行 `scripts/build.ps1` 构建，再运行 `scripts/verify.ps1`。验证会使用新的隔离目录，不向正式版导入测试书籍。原始窗口报告与渲染图保存在 `artifacts/qa-portable-01/`。
