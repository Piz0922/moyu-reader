# 摸鱼阅读器第一版规格

日期：2026-10-30。状态：用户已确认并授权制作；第一版已实现，验证范围见 [validation.md](validation.md)。

## 目标

制作 Windows 桌面悬浮阅读器，使正文像贴图一样可随意摆放在网页或其他应用之上。鼠标进入正文不改变界面，不出现黑底文字提示、悬浮说明或自动工具栏。

## 阅读区域

- 跨应用置顶，无标题栏、可见边框、阴影、常驻按钮及常驻滚动条。
- 默认白底深灰字，背景颜色和透明度可调。
- 正文不可选中；按住正文拖动整个区域。
- 靠近边缘时仅用鼠标指针形状表示缩放方向。
- 四角：阅读区域宽高与字号等比缩放。
- 四边中点：只调整宽度或高度，字号不变，正文重新换行。
- Ctrl＋滚轮：只调整字号。
- 普通滚轮：正文连续滚动，跨章衔接，不变成逐页翻页。
- 缩放、字号调整和重新换行尽量保持视口顶部附近的正文位置。
- 初始字号范围 8～72，区域最小约 160×100；等比缩放触及任一限制时整体停止，不能破坏比例。
- 正文右键显示主动操作菜单，提供书架、文件打开、目录和设置等入口。

## 页面与托盘

- 书架和阅读页一次只显示一个；各自保留自己的尺寸。
- 从阅读进入书架先隐藏正文；打开书籍后收起书架，在原悬浮位置继续阅读。
- 双击正文隐藏整个阅读区域，屏幕不留恢复标记。
- Ctrl＋Alt＋空格默认切换隐藏／显示，可自定义；快捷键冲突在设置中提示。
- 单击托盘图标恢复隐藏前的页面；恢复阅读时不主动抢走其他应用的键盘焦点。
- 托盘右键菜单包含“书架、设置、退出”，右键本身不直接打开书架。
- 关闭页面只隐藏；只有托盘菜单的“退出”才结束程序。
- 首次启动显示书架；以后恢复上次页面及对应阅读进度。
- 提供“找回窗口”能力，经托盘的设置入口可访问，使移出可见屏幕的阅读区域恢复可见。

## 书架与文件

- 支持 TXT 和普通可重排 EPUB。
- 书架为紧凑列表，显示书名、格式、阅读进度，按最近阅读排序。
- 支持搜索、拖入文件、按钮导入、打开和移除书籍。
- EPUB 使用统一字体与配色，保留章节和插图；插图适应阅读区域宽度。
- 首版不做封面墙，不支持漫画、固定版式或带 DRM 的电子书。
- 导入时保存独立书库副本。移动或删除原文件不影响已导入书籍。
- 从书架移除书籍只清理受程序管理的副本及记录，绝不删除用户原文件。

## 保存与交付

- 程序所在目录下有独立资源目录，书籍、配置和阅读记录分类保存。
- 每本书单独保存进度；窗口位置、阅读区域尺寸、字号和外观采用全局设置，切书不改变区域尺寸。
- 所有用户数据本地保存。复制或移动整个程序文件夹可一并带走书库、设置和进度。
- 资源目录不可写时明确提示，不静默改用其他存储位置。
- 交付 Windows 便携版程序文件夹和完整源码。解压后双击 EXE 运行，依赖尽量随包提供，不要求用户安装开发环境。

## 核心验收场景

1. 鼠标进入正文、停留或离开时，不出现任何悬停文字信息或自动工具栏。
2. 正文拖动、边缘拉伸、四角等比缩放、普通滚动和 Ctrl＋滚轮字号调整互不混淆；双击可可靠隐藏。
3. 调整宽度或字号后仍能接着读原来附近的正文，连续滚动可通过章节边界。
4. 隐藏阅读页后单击托盘恢复阅读页；隐藏书架后单击托盘恢复书架。书架和正文不会同时占屏。
5. 托盘右键弹出含书架、设置和退出的菜单，关闭页面不退出进程，菜单退出则保存并结束程序。
6. 导入 TXT 与 EPUB，退出再启动后可恢复页面与进度；切书时阅读区域尺寸不跳变。
7. 导入后移动原文件仍可阅读；从书架移除后原文件仍存在且内容不变。
8. 整体移动程序文件夹后，书库、设置和进度仍可用；资源目录不可写时得到明确提示。
